🔄 官網重建：五階段過稿流程

為確保專案品質與雙方權益，官網重建依照以下五個階段執行，每階段均需客戶書面確認後方可進入下一階段。

A
網站企劃與架構規劃

Sitemap 規劃、頁面動線確認、功能規格確認、設計風格定調。此階段如需調整，可修改一次。

📦 產出：Sitemap 架構圖、規格書確認單
B
視覺設計稿提案

首頁及指定頁面 UI 設計稿提交，含 StyleGuide 規範。整體風格與排版規劃至多修改兩次。

📦 產出：Figma / PDF 設計稿、StyleGuide 文件
C
前端切版建置

依設計稿進行 Desktop / Tablet / Mobile 三版切版，此階段僅可修改圖片與細部文案，不接受版型變更。

📦 產出：可瀏覽之測試網址
D
功能測試與驗收

依規格書逐項功能測試，含表單、問卷、預約系統、行銷工具串接。如有規格外需求，須另行估價。

📦 產出：功能測試清單、驗收確認單
E
正式上線 + 後台教學

DNS 切換上線、Google Search Console 送審、後台操作線上教學（2 小時）。上線後僅可修改細部文案，功能調整依年度維護方案執行。

📦 產出：上線通知、教學錄影、操作手冊
⚠️ 超出修改次數說明：各階段修改次數如超出上限，雙方須以書面協議額外費用後方可執行。如協議不成或修改請求窒礙難行，確認鍵有權終止該階段，已支付費用不予退還。
