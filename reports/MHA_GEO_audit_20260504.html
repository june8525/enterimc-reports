2.3 核心問題 Top 5

#1
FAQPage / HowTo / Service Schema 仍缺 → 失去最大引用率倍增器

首頁與內頁 Schema 已部署 LocalBusiness、Organization、Person、BreadcrumbList、BlogPosting（基礎相當扎實），但 /faq-materials/、/faq-service/ 等 FAQ 頁仍缺 FAQPage Schema，施工流程頁仍缺 HowTo Schema、各服務頁缺 Service Schema。FAQPage 部署後 AI 引用率 15→41%（×3.2），是現階段單一最大改善槓桿。

#2
首頁 H1 為空字串 → AI 對首頁主題判斷模糊

https://mha-eco.com/ 的 DOM 中 H1 元素陣列為空（document.querySelectorAll('h1') 回傳 0 個）。內頁如 /grafton/、/about-advisors/、/mha-certifications/ 都有正確 H1，但首頁這個關鍵入口缺 H1，會降低 AI 對品牌主題的權威識別度。

#3
缺核心 Pillar 整合頁 → 知識文未形成主題權威叢集

妙健已有不少優質 Cluster 文章（「台北除甲醛公司怎麼選 三大判斷指標」「WHO 公告甲醛」「除甲醛效果關鍵在施工細節」「室內空品成新顯學 妙健以日系長效技術引領系統化治理新典範」），但缺一個整合性的「台灣甲醛治理完整指南」Pillar 頁把這些 Cluster 文章串起來。AI 在被問通用問題時，會拿單一 Cluster 文回答，無法把妙健識別為「該主題的中心節點」。

#4
文章無作者署名欄位 → YMYL E-E-A-T 信號未顯化

妙健已有 4 位顧問具名（柯錦和博士、洪宇軒醫師、孫因理事長、陳哲郎建築師）+ 2 位董事於 /about-advisors/ 頁面具名展示，個別文章也引用具名專家發言（如「孫因建議選擇除甲醛公司應確認技師訓練...」）——但每篇文章頁缺乏「by 作者」署名欄位，未在 BlogPosting Schema 中填入 author 節點指向 Person Schema。現有的 Person Schema 只有顧問頁本身的，文章引用作者沒被結構化。

#5
維基百科無條目 + 論壇 UGC 為零 → 兩個 ChatGPT 引用權威節點缺席

zh.wikipedia.org/wiki/妙健環境科技 顯示「目前還沒有與上述標題相同的條目」；Mobile01 site 搜尋無妙健 / 除甲醛 GRAFTON 相關文件。新聞媒體（CNEWS、UDN、ETtoday、工商時報）已有 2025 年報導具備 Wikipedia 引用來源條件，現在送審即可。論壇 UGC 則需另外操作。
