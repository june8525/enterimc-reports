⚙️ 第一層：技術可達性（Pass / Fail 必要條件）

⚠ 層級說明：技術可達性為封鎖層，任何 Fail 項目會阻斷後續所有 GEO 效益。本層評估 AI 爬蟲可訪問性與基礎技術條件，禾雅整體技術基礎良好，但缺少 llms.txt 為主要缺口。

A 區：AI 爬蟲可訪問性

檢查項目狀態說明
robots.txt 設定WARNWordPress 預設 robots.txt 存在，但未明確開放主流 AI 爬蟲（GPTBot / ClaudeBot / PerplexityBot）。建議明確允許。
llms.txt 建立FAIL未建立 llms.txt，AI 爬蟲無法取得網站高價值內容的優先引導清單，衛教文章與療程頁曝光機會大幅降低。
XML SitemapPASSWordPress 自動生成 Sitemap，基礎覆蓋良好。
IndexNow 部署FAIL未部署 IndexNow，新內容發布後無法即時通知 Bing/Perplexity 更新索引。

B 區：技術基礎

檢查項目狀態說明
HTTPS 安全連線PASS全站 HTTPS，SSL 憑證有效。
RWD 行動裝置適應PASS導覽與內容在行動裝置上正常顯示。
網頁載入速度WARN首頁含大量 webp 圖片與動態元素，建議定期以 PageSpeed Insights 監控 Core Web Vitals，確保 LCP < 2.5s。
JavaScript 渲染依賴PASS主要內容非 JS 渲染，AI 爬蟲可直接讀取 HTML 文字內容。
內容可索引性PASS療程頁、衛教文章、團隊介紹均可正常爬取。

立即修復建議（第一層）

  • ①立即 建立 /llms.txt，列出所有療程頁、衛教文章、醫師介紹、診所頁的 URL 與摘要，為 AI 爬蟲提供內容優先地圖。
  • ②高 更新 robots.txt，明確允許 GPTBot、ClaudeBot、PerplexityBot 爬取，同時確保 /wp-admin/ 等管理路徑仍受保護。
  • ③高 安裝 WordPress IndexNow 外掛（Rank Math 已內建支援），每次新文章發布自動通知 Bing 與 Perplexity 即時更新。
