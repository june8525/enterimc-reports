1.3 核心問題 Top 5

問題 #1
技術層
JS 動態渲染壁壘：官網以 .php + JavaScript 動態渲染架構呈現，AI 爬蟲（GPTBot、Bingbot）無法有效解析 JavaScript 執行後的內容，導致知識庫文章在 AI 訓練與即時引用時幾乎不可見。這是封鎖所有後續 GEO 效益的根本問題。
問題 #2
語意層
Schema 結構化資料嚴重缺失：整站未偵測到 FAQPage、MedicalDevice、HowTo、Organization + sameAs（FDA 連結）等關鍵 Schema。AI 平台無法以機器可讀格式識別產品特性、醫療主張與品牌可信度。
問題 #3
可信度層
作者具名與醫師審閱聲明缺失：知識庫（魔滴美胸學院）文章均未標示具名整形外科醫師作者或醫學審閱人，這在 YMYL 醫療類目中是 Google AIO 拒絕引用的主要原因，E-E-A-T 信號極弱。
問題 #4
語意層
Answer-First 段落結構缺失：知識庫文章雖有相當篇幅，但多數為行銷導向敘述，缺乏 AI 可直接萃取的「自給自足段落」（問題 → 直接答案 → 支持依據），導致 AI 引用率極低。
問題 #5
品牌層
第三方媒體引用來源稀少：官網自身內容豐富，但第三方台灣中文媒體（新聞媒體、醫療論壇、衛教平台）的有效引用連結稀少，AI 平台（尤其 ChatGPT / Perplexity）主要引用第三方 Earned Media，官網本身作為引用來源的能力有限。

第二章 · 第一層：技術可達性

Layer 1 · 技術可達性 — Pass / Fail 必要條件

⚠ 重大警示：官網 JavaScript 動態渲染架構（.php + JS）為 AI 爬蟲最大壁壘。GPTBot、ClaudeBot、Bingbot 等主流 AI 爬蟲對 JS 渲染頁面的內容解析能力有限，意味著知識庫中 10+ 篇文章的內容，即使存在索引，AI 看到的也可能是空白殼。此問題不修復，其餘所有優化效益將大打折扣。

A 區：AI 爬蟲可訪問性

檢查項目現況狀態說明
robots.txt 對 AI 爬蟲開放 需驗證 WARN 需確認 GPTBot、ClaudeBot、Bingbot 未被 Disallow
llms.txt 部署 未偵測 FAIL 未建立 /llms.txt，AI 爬蟲無法快速識別網站重要內容入口
JS 渲染後內容可索引性 高風險 FAIL .php + JS 動態渲染，AI 爬蟲讀取 DOM 前內容幾乎為空
IndexNow 部署 未偵測 FAIL 缺乏即時通知 Bing / Yandex 索引更新機制
Bing Webmaster 驗證 未確認 WARN ChatGPT Search 引用來源 87% 來自 Bing Top 10，Bing 索引至關重要
XML Sitemap 完整性 存在但需審查 WARN 需確認知識庫所有文章 URL 均已列入 sitemap

B 區：技術基礎

檢查項目現況狀態說明
HTTPS 全站啟用 ✓ 已啟用 PASS SSL 憑證正常，HTTPS 全站強制跳轉
RWD 行動裝置相容 ✓ 已支援 PASS 響應式設計，行動體驗正常
頁面載入速度 中等偏慢 WARN JS 動態渲染增加 TTFB，影響 AI 爬蟲抓取優先度
多語言 hreflang 標記 部分（zh-tw） WARN 需確認英文版 /en/ 路徑的 hreflang 配對是否完整

立即修復建議

  • ①SSR / 預渲染部署：針對知識庫文章頁面優先導入 Server-Side Rendering 或靜態預渲染（如 Prerender.io），讓 AI 爬蟲獲得完整 HTML 內容。此為技術層最高優先項目。
  • ②建立 /llms.txt：於網站根目錄部署 llms.txt，清單列出知識庫所有重要文章 URL，協助 AI 平台快速識別內容入口。
  • ③審查 robots.txt：確認 GPTBot、ClaudeBot、Anthropic-AI 等 AI 爬蟲 User-agent 未被 Disallow，同時加入 Sitemap 宣告。
  • ④部署 IndexNow：每次知識庫文章更新後，即時通知 Bing 重新索引，強化 ChatGPT Search 引用來源基礎。

第三章 · 第二層：語意架構（最關鍵，佔 35 分）

Layer 2 · 語意架構 — 得分 15 / 35 分

評分說明：語意架構是預測 AI 引用最關鍵的單一層級，佔總分 35%。研究顯示自給自足段落與 AI 引用相關係數達 r=0.87。Motiva 官網在此層得分偏低（15/35），主要問題集中於 Answer-First 結構不足、Schema 完全缺失兩大面向，修復效益最高、改動成本相對可控。

Answer-First 段落結構

D 區：Schema 結構化資料

⚠ 嚴重缺失：根據研究，65% 被 AI Mode 引用、71% 被 ChatGPT 引用的頁面含有 Schema 結構化資料。Motiva 官網目前幾乎無任何 Schema 部署，錯失最直接的 AI 可讀性強化機會。
Schema 類型建議部署位置現況重要性

FAQPage 知識庫所有文章 FAIL 極高
Organization + sameAs
連結至 FDA、ESTA 官網		 首頁 / 關於頁 FAIL 極高
Article + author
含醫師作者資訊		 知識庫所有文章 FAIL 高

立即修復建議

  • ①知識庫文章全面重構為 Answer-First 格式：每篇文章首段加入「直接回答段落」（50-80 字），格式：問題陳述 → 直接答案 → 數據支撐。這是 AI 萃取引用的核心素材。
  • ②部署 FAQPage Schema：優先於熱門文章（隆乳費用、魔滴特色、術後照護）加入 FAQPage JSON-LD，可使 AI 引用率提升 3.2 倍（FAQ Schema vs 一般頁面）。
  • ③部署 MedicalDevice Schema：Ergonomix® / Motiva JOY 產品頁加入 MedicalDevice 類型，標記審核機構（衛福部食藥署）、製造商（ESTA）、適應症。
  • ④首頁 Organization Schema + sameAs：連結 FDA 審核頁、ESTA 官網、NASDAQ 股票代碼頁，建立可溯源的實體權威信號。
  • ⑤各文章加入比較型表格：如「魔滴 vs 傳統矽膠植入物比較」、「一代 vs 二代功能差異」，比較型清單佔全體 AI 引用的 32.5%（最高單一格式）。
